影子校验（切流前试跑）

开启后在 {{ shadow_window }} 秒窗口内发送试传报文建立新会话（不填固定端口）。 该会话前 {{ shadow_limit }} 条上行会同时发往固定接收器和另一台接收器，只有固定接收器的回包下发终端。 两侧回包按“原文 + 次数”比较（乱序、同文重发不会误判）；缺包、发送失败或超过 {{ shadow_limit }} 条标为证据不足。 本次比较的两侧在开启时固定，切换目标不改变它们；校验结束、会话过期或重启后停止镜像，迟到回包不会串入下一次。
